Passo 6 · 8 minuti

Controlla e pubblica

Prima di mettere il link nel CV fai i controlli. Poi scarica la pagina e mettila online gratis.

    Mettila online gratis con GitHub Pages
    1. Crea un account su github.com.
    2. New repository → nome portfolio → Public → Create.
    3. «uploading an existing file» → carica index.html → Commit changes.
    4. Settings → Pages → «Deploy from a branch» → main e / (root) → Save.
    5. Dopo circa un minuto è online.
